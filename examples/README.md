# Examples

Do **not** copy example repos into new projects. Use them as **reference** when filling placeholders.

| Reference | Good reference for |
|-----------|-------------------|
| [AGENTS.example.md](AGENTS.example.md) | **Quality bar** — a fully filled `AGENTS.md` for a fictional satellite app |
| [meavo-gateway](https://github.com/meavo-booths/meavo-gateway) | **Reference implementation** — its `AGENTS.md` is the deep-dive companion to STANDARDS.md (auth, tool cards, notifications, UI system, deployment) |
| [meavo-db](https://github.com/meavo-booths/meavo-db) | Schema-owned repo, `data-model.md` as primary doc, migration safety |
| [hols](https://github.com/meavo-booths/hols) | Satellite app with tool-card gating (`getHolsUser()` pattern) |
| [sales](https://github.com/meavo-booths/sales) | Next.js + shared navigation scaffold, Google-only auth |
| [meavo-rp](https://github.com/meavo-booths/meavo-rp) | Legacy/pre-standard app: domain layer, sheet sync, personas, `docs/domain.md` depth |

When bootstrapping, **discover the target repo first** — then borrow *patterns*, not prose.
